# 🐗 Psina Engine

## 📱 Как играть с телефона — гайд

### 1. Скачивание
1. Открой [релизы](https://github.com/pyBIrtat/PsinaEngine/releases/latest) и скачай **`PsinaEngine-…-arm64-v8a.apk`** — подходит почти всем современным телефонам (Samsung, Xiaomi, Pixel и т.д.). Если не знаешь архитектуру — бери полную **`PsinaEngine-….apk`** (без суффикса).
2. Открой скачанный файл → Android спросит про установку из неизвестного источника → разреши для браузера → «Установить».
3. Google Play Protect может предупредить — это нормально, приложение собирается открыто из исходников (GPL), нажми «Всё равно установить».

### 2. Первый запуск клиента
1. Открой **Psina Engine** → кнопка **«Клиенты Псины»** под «Запустить игру».
2. Выбери клиента в списке (сверху — готовые к запуску, есть поиск по имени/версии) → **«Играть»**.
3. Подтверди «Это не ванильный Minecraft» → всё произойдёт само:
   - скачается ванильная база нужной версии (один раз, ~300–500 МБ, с прогрессом);
   - поставится сам клиент;
   - игра запустится.
4. Ник и память (RAM) меняются тапом по строке с ником над списком.

### 3. Управление
Настройка экранных кнопок: «Клиенты Псины» → тап по строке с ником → **«Кнопки управления»**. Там же настраиваются готовые раскладки или своя — размер, прозрачность, любые кнопки.

### 4. Если что-то пошло не так
- **«Манифест недоступен»** — нет интернета или GitHub недоступен; жми «Повторить».
- **«Устанавливаю Minecraft …» зависло** — проверь сеть, отмена и повтор безопасны.
- **«Запуск отправлен», но игра не открылась** — запусти игру вручную из списка версий лаунчера.
- **Экспериментальные клиенты** (с подписью «экспериментально») могут не запуститься — это честно указано в их описании; напиши владельцу, что за ошибка.
- Логи ошибок: настройки Android → Приложения → Psina Engine → принудительно закрыть, потом повторить — ошибка покажется снова в диалоге.

### 5. Как это работает (коротко)
Манифест клиентов лежит в [PsinaLauncher](https://github.com/pyBIrtat/PsinaLauncher) — лаунчер качает его при запуске (raw GitHub, всегда свежий). Клиенты — Fabric-моды: скачиваются по прямым ссылкам с проверкой sha256, ставятся в инстанс и запускаются движком самого приложения (форк ZalithLauncher2 = полноценный Minecraft-рантайм на Android). Для клиентов со своим лоадером (β-эксперимент, например Нурсултан) создаётся отдельная версия с их mainClass поверх ванили.

### 6. Версии и обновления
- Новая версия APK публикуется в [релизах](https://github.com/pyBIrtat/PsinaEngine/releases) — просто ставь новый APK поверх старого, данные сохранятся.
- Клиенты обновляются сами: если автор выпустил новую сборку, при следующем «Играть» она скачается вместо старой.
- ПК-версия Псины: [PsinaLauncher](https://github.com/pyBIrtat/PsinaLauncher/releases) — релиз v1 (jar и логотипы клиентов там же).

Мобильный Minecraft-лаунчер для Android — движок для запуска клиентов «Псины» на телефоне.
Форк [ZalithLauncher2](https://github.com/ZalithLauncher/ZalithLauncher2) (автор оригинала — Movtery и контрибьюторы), лицензия GPL-3.0.

Внутри — полноценный Minecraft: офлайн- и Microsoft-аккаунты, установка версий и Fabric, моды, изоляция игровых папок, сенсорное управление.

## Отличия от апстрима (GPLv3 §7)

- applicationId / namespace: `ru.psina.engine`; имя — **Psina Engine**; версия — `2.6.1-psina.1`
- action filemanager-сервиса: `ru.psina.engine.filemanager.EVENT_SERVICE`
- родные README апстрима перенесены в [docs/](docs/): `UPSTREAM-README.md`, `UPSTREAM-README_EN_US.md`, `UPSTREAM-README_ZH_TW.md`
- в работе: перенос ядра ПК-лаунчера [Псины](https://github.com/pyBIrtat/PsinaLauncher) и кнопка «Играть» для наших клиентов прямо из лаунчера

## Сборка

- JDK 21 + Android SDK
- `./gradlew ZalithLauncher:assembleDebug`
